Khắc phục: Web Bluetooth Bị Chặn

Web Bluetooth API globally disabled

1. Mở file trực tiếp (file:///) — Nguyên nhân phổ biến nhất: Trình duyệt Chromium (Chrome/Edge) chặn 100% tính năng Bluetooth khi mở file trực tiếp từ ổ cứng.
👉 Cách khắc phục: Chạy file start_web.bat trong thư mục dự án để mở trang qua http://localhost:8080.
2. Nếu bạn đang dùng Brave Browser: Brave tắt Bluetooth mặc định để bảo mật vân tay số.
👉 Cách khắc phục: Dùng Google Chrome hoặc Microsoft Edge. Hoặc mở brave://settings/content/bluetoothDevices và chọn "Sites can ask to connect to Bluetooth devices".
3. Kiểm tra Bluetooth máy tính: Đảm bảo công tắc Bluetooth trên máy tính đã được Bật (ON) trong Windows Settings > Bluetooth & devices.
